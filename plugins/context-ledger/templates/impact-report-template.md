## Usage

This report is auto-generated by `/ledger-update`. The agent:

1. Compares previous and current state of changed artifacts
2. Traces all references to changed IDs
3. Identifies affected downstream documents
4. Generates action items based on impact severity

### Interpreting Impact

**Direct impact:** Downstream doc explicitly cites the changed ID
**Indirect impact:** Downstream doc cites something that cites the changed ID
**Potential impact:** Semantic overlap without explicit citation

### Acting on This Report

1. Start with "Immediate" actions
2. Review each affected section in context
3. Decide if regeneration or manual edit is appropriate
4. Mark completed actions in this report for audit trail

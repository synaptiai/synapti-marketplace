# Gate: Plan Readiness

## What It Replaces
Manual plan review.

## Pass Criteria
1. Every phase has explicit acceptance criteria
2. Zero unresolved assumptions — every assumption is either verified or flagged
3. Ambiguous requirements have been clarified through research
4. Verification methods are defined per deliverable type
5. Dependencies and risks are surfaced with mitigation strategies
6. Tasks are created and trackable
7. The Stranger Test passes: another agent could execute this plan without asking questions

## Satisfaction Metric
Target: 90% first-pass approval.

## On Fail
- Self-review: Agent re-reads plan against each criterion, fixes gaps
- Escalate after two self-review passes with documented improvements
